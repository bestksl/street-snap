# 影调参考与本地调校

途帧的影调由公开公式生成，没有使用厂商固件、提取色表或原厂 LUT。相机名称用来说明风格参考，预设不代表对应机型的准确输出。手机的传感器、镜头、曝光、白平衡和 ISP 都会影响结果。

## 粉末蓝 / Powder Blue

参考 [SIGMA Color Mode Library](https://www.sigma-global.com/en/shooting-with-sigma/sigma_color_mode_library/#Powder%20Blue)。官方说明是明亮、通透、清新的蓝色，并指出中间调比 Standard 更亮。页面提供三组同场景 Standard / Powder Blue 对比；本次同时查看了其中的人像对比，暗色衣物和背景偏蓝青，面部仍保留暖色。

旧实现主要响应已经很鲜艳的蓝色，普通阴影、灰蓝和深蓝几乎不变。本次调整为：

- 提升中间调，保留纯黑和纯白端点。
- 扩大深蓝、灰蓝的响应，柔化蓝色饱和度并向青蓝靠拢。
- 给暗部少量蓝青倾向，对暖色主体减弱这部分偏色；不会给整幅图覆盖蓝色蒙版。

公式系本项目独立调校，未对官方样张反向拟合或提取 LUT。官方图片仅用于本地视觉参照，不随应用或仓库分发。当前结果仍需通过白天人像、阴天街景和夜景的真机照片继续校准。

## 按相机风格整理

| 分组 | 预设 | 本项目的表现方向 |
| --- | --- | --- |
| 理光 GR | 正片、负片、高反差黑白 | 鲜明正片；柔和冲印色调；较硬的黑白对比 |
| 富士 X100 | CC / 经典正片 | 克制的颜色，更结实的阴影 |
| 富士 X100 | NC / 经典负片 | 较硬的明暗关系、暖亮部与冷暗部、较深的绿植 |
| 富士 X100 | NA / 怀旧负片 | 琥珀色亮部、保留阴影层次 |
| 富士 X100 | ACROS / 黑白 | 平滑黑白层次，比高反差黑白保留更多暗部 |
| 适马 fp | 粉末蓝 | 通透中间调、清淡蓝青、保留暖色主体 |
| 松下 LUMIX | 自然、L.单色 | 温和饱和度与中性灰；略有黑位余量的黑白 |

富士的公开方向参考 [X100VI 官方手册：Film Simulation](https://fujifilm-dsc.com/en/manual/x100vi/menu_shooting/image_quality_setting/#film_simulation)。手册对 Classic Chrome、Classic Neg.、Nostalgic Neg.、ACROS 分别描述为柔和色彩与增强阴影对比、较硬影调与鲜明色彩、琥珀高光与丰富阴影、细节丰富的黑白。NC、NA 是应用内短标签；不代表厂商统一的官方缩写。X100 不同代机型自带的模拟模式也不同。

自然和 L.单色是本项目独立编写的两种温和风格，并未对特定 LUMIX 机身进行色卡测量或匹配。黑白颗粒由通用颗粒参数控制；预设名称不等于模拟了胶片的全部物理特性。

## HDF 高光扩散

参考 [RICOH GR III / IIIx HDF 官方说明及开关对比](https://www.ricoh-imaging.co.jp/english/products/gr-3/special/hdf/)。HDF 是 Highlight Diffusion Filter，核心是光线在亮部及其周围扩散、降低局部对比。这里实现的是软件柔光，不是物理滤镜，也不是 HDR 多帧合成。

本次保留最多两张、最长边 384 px 的 GPU 缓冲，将提取后的高光做两档半径的水平、垂直扩散，再叠回原图。默认强度下，灯光和亮窗周围的光晕比之前更宽、更明显；中灰低于亮部提取阈值，避免无高光场景整体发灰。HDF 关闭或强度为零时跳过额外通道；照片各条带共享同一张完整画面的柔光纹理。

预览与成片共用实现。已用合成高光场景检查着色器编译、默认强度光晕、远处暗部、无高光灰场、零强度恒等和条带连续性。以上检查验证算法行为，不等于荣耀手机上的帧率、功耗或光学效果实测。
