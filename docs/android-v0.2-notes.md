# Android v0.2 · 影调与操作

本版补齐影调微调、白平衡和柔光，使用与 v0.1 相同的包名与本地开发签名，可以覆盖安装并保留原有参数与导入的 LUT。

## 影调

- **正片**：更深的阴影、更鲜明的颜色，参考 GR 正片模式的方向。
- **负片**：柔和的暗部、暖色主体与较柔的高光，参考 GR 负片模式的方向。
- **粉末蓝**：参考适马 Powder Blue 的清新蓝色、明亮通透和中间调提亮。
- 原色、黑白、晴街与自定义 `.cube` 仍可使用。

以上为独立编写的风格模拟，不使用厂商提取的 LUT。适马的公开参考为 [Color Mode Library](https://www.sigma-global.com/en/shooting-with-sigma/sigma_color_mode_library/#Powder%20Blue)；实现与处理顺序见 [行色模块](../color/README.md)。

每套滤镜单独保存强度、饱和度、色相、对比、亮度、高光、阴影、锐度、清晰度、颗粒和暗角。带正负值的参数显示为 −4…+4 档；数值表示本项目的调节幅度，与原厂菜单没有数值对应关系。「重置当前影调」只重置选中的滤镜。

## 快门附近的控制

- **HDF**：一键启停软件柔光。在 ADJ 的「柔光」参数里调强度；它让高光向周围扩散，保留主体细节。
- **ADJ**：展开影调、白平衡、拍摄三个页签；选择参数后使用滑杆或加减键调整。
- **WB**：直接进入白平衡，提供设备支持的自动、日光、阴天、阴影、白炽灯与荧光灯选项。
- **白平衡漂移**：拖动 A–B / G–M 坐标，或用加减键微调；各轴 −9…+9，支持归零。
- **拍后反馈**：保存成功后更新快门旁的最近照片缩略图，轻点查看；保存中由快门显示进度，失败才弹提示，不再逐张弹出成功消息。

白平衡预设由 Camera2 控制相机，漂移在 GPU 中作用于预览和 JPEG。柔光和白平衡为全局设置，切换滤镜时保留。当前不提供未经设备校准的开尔文色温控制。

常规窗口下面板展开时保留取景与快门，音量键仍可拍照；相同比例的取景区域缩放不重建相机会话。宽横屏使用右侧控制区，小窗口改为可滚动布局，主要触控目标至少 48 dp。

## 首轮试拍

1. 覆盖安装，确认旧焦段、曝光和 LUT 仍在。
2. 分别修改正片、负片、粉末蓝的饱和度与锐度，切换后再回来，检查各自的参数记忆。
3. 对着窗边、反光物体或夜间点光源开关 HDF，对照取景与成片；普通低反差场景的效果应较轻。
4. 在日光与室内分别切换 WB，并调 A/B、G/M 漂移；确认成片方向与预览一致。
5. 展开、收起 ADJ，旋转与切换内外屏，确认快门可达且取景正常。

这是开发试拍版。新影调、柔光、白平衡及布局在荣耀 Vs3 上的观感、帧率和温升仍待实拍记录。
