# 胶片与对焦 · 开发记录

本次更新位于源码与本地试拍 APK 中；已发布的 v0.2.0-dev Release 不会随源码自动更新。

## 对焦

自动对焦一直由 CameraX 管理。这次把入口与状态补齐：拍摄面板提供 **AF 自动 / MF 预设**；点按画面对焦，长按成功后显示 **AF-L**，点 AF-L 或 AF 自动解除锁定。MF 模式下保留预设距离，点击取景不会偷偷改变焦点。

白框表示正在对焦，黄绿框表示合焦，橙框表示未合焦。未合焦仍能拍摄。一次对焦最多等待 5 秒，连续点按只接收最新请求的反馈，切换 MF、关闭相机和解锁会清除旧状态。不支持点按对焦的设备不开放该手势。

CameraX 1.5.1 的 `setCaptureRequestOptions` 会替换之前的 interop 参数。AF 路径不写 `CONTROL_AF_MODE`；离开 MF 时移除 `AF_OFF` 和手动距离，让 CameraX 协调持续 AF 和点按 AF。强制写持续 AF 会覆盖点按对焦所需的 AUTO 请求，因此这里不采用该做法。

## 胶片

点快门上方的「胶片」进入胶片配置；也可从 ADJ → 胶片进入。参考给定界面的胶片卡片、边框、日期配置结构，卡片由 Compose 绘制，不引入第三方 App 图片。

| 胶片 | 调校方向 |
| --- | --- |
| 日光 250 | 微暖、柔和反差、细颗粒 |
| 钨光 500 | 冷影暖光、压制亮部、较明显颗粒 |
| 反转 100 | 浓郁色彩、紧实暗部、清晰轮廓 |
| 日光 50 | 明净暖色、低颗粒 |
| 柔彩 200 | 青绿与明亮中间调、柔软细节 |
| 银盐 400 | 黑白、较粗颗粒 |
| 人像 400 | 柔暖肤色、低反差、柔和高光 |

配方是基于现有 LUT 与调节参数独立编写的模拟。编号不设置传感器 ISO；没有第三方样片或色表作为测量依据，不能视为截图 App 或原厂胶片的精确复刻。

每卷独立保存强度、饱和度、颗粒等调整；重置回该卷默认配方。「卸下胶片」恢复之前的普通影调。选择普通影调或导入 LUT 会退出胶片；白平衡、HDF 为全局设置。旧版参数继续兼容。

边框提供无、白边、黑边和底片边，日期提供关闭、日期、日期与时间。边框使用完整照片等比缩入，不遮掉原始画面边缘，输出像素尺寸不变。边框和日期仅写入 JPEG，卡片下方的小图是边框示意，取景仍显示完整画面。日期取按下快门时的本地时间；配方、边框和日期状态都在同一时刻固定，后台处理中切换设置不会影响已拍照片。不开启日期时不会添加任何文字。

这次不加入没有拍摄行为差异的机身皮肤选择器；现阶段保留途帧的三档视角与原有快门布局。

## 本轮验证

2026-10-16：Debug / Preview APK 构建通过，50 项单元测试通过；Lint 为 0 error、16 warning（依赖版本、图标和代码简化提示等）。Preview 已启用 R8 与资源裁剪，约 3.3 MB。

Android 15 模拟器验证了胶片选择、覆盖安装后保留设置、长按进入 AF-L、解锁回 AF、选择普通影调退出胶片，以及继续拍照。胶片 + HDF 和原色两条路径都保存了带白边、日期时间的 JPEG；检查成片为 960 × 1280、方向为正向，保留曝光等 EXIF，未出现崩溃。模拟器的分辨率与耗时不作为真机性能数据。

## 真机验收

- 荣耀 Vs3：对着近物与远景，检查 AF 连续调整、点按位置、长按锁定、解除锁定、MF → AF 后重新合焦。
- 低光与快速连续点按：检查失败反馈、快门可用，切换白平衡与焦段后不长时间置灰。
- 逐卷调颗粒与饱和度；切换、重启、重置与卸卷后检查参数隔离。
- 无/白/黑/底片边各拍一张，横竖屏检查完整构图、日期位置和 EXIF 方向。
- 按快门后马上换胶片/边框：先前一张仍使用按快门时的设置。

模拟器可以验证布局、设置与 JPEG 保存，不能证明荣耀镜头真实合焦、胶片实拍观感或热稳定性。端侧模型尚未接入，评估见 [端侧多模态方案](edge-model-plan.md)。
