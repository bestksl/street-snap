# 界面截图

三张图片来自本轮内置 CPU Int8 模型的实际 Debug APK，运行于 Android 15（API 35）ARM64 模拟器。取景是模拟器内置 virtualscene 测试房间，截图不代表荣耀 Vs3 真机或实际摄影效果。

- `viewfinder.png`：可见推荐构图框、对应中文建议、来源和分阶段耗时，以及主动“构图”按钮和可选“实时”入口。
- `camera-picker.png`：相机形象与横持/竖持选项。
- `edge-models.png`：构图辅助、实时开关、模型选择和已安装251.2MB状态。

蓝色推荐框来自当前图像统计，绿色AI框只有真实模型选择且通过候选换序一致性检查才会显示。中文提示来自候选的规则理由。模型未明确选择时保留画面分析建议，不伪造AI成功。

截图直接用ADB screencap取得，原始1080×2340按比例缩至720×1560；不拼接取景或虚构控件。UI截图为README展示材料，原始测试输入与照片仅保存在被Git忽略的本地目录。三档焦段按设备能力开放，模拟器显示原生视角。

更新截图时同步检查README描述。默认Preview不带权重，本轮显式内置调试包约300MB；不能仅看默认Preview包体判断模型是否存在。
