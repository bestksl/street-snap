# 界面截图

这三张图片来自当前实际 Preview APK，运行于 Android 15（API 35）AOSP ARM64 模拟器，使用内置 `virtualscene` 后置相机。截图用于展示操作界面，不代表真机拍摄效果。

- `viewfinder.png`：顶部相机摆件、AF、HDF、三档视角入口、胶片快捷项与快门。
- `camera-picker.png`：五个相机摆件、自动/横持/竖持方向和次级设备诊断入口。
- `edge-models.png`：端侧构图辅助开关、SmolVLM 256M / 500M 选择、模型安装状态和快门不阻塞说明。

28 / 35 / 50mm 三档按钮固定显示，只有设备支持的视角可以切换；不支持的选项置灰，并在下方说明原因。图中模拟器使用「原生视角」，不会将未标定的画面标成某个等效焦段。真实设备按相机能力启用对应视角与白平衡预设。

## 更新方式

构建并安装 `:app:assemblePreview`，在应用中打开对应面板，用 ADB 截图：

```sh
adb -s <设备序列号> exec-out screencap -p > screenshot.png
```

当前截图原始分辨率为 1080 × 2340，等比缩小为 720 × 1560 后存入此目录。保留完整界面，不拼接预览画面或伪造控件状态。模型图显示未安装状态，不暗示权重已打入 APK。更新时同步检查 README 的三列图片与描述。
