# 界面截图

三张图片来自安装在 Android 15（API 35）ARM64 模拟器上的 Preview APK（2026-10-18，全屏取景器新 UI）。取景为模拟器内置 virtualscene 测试房间，截图不代表荣耀 Vs3 真机或实际摄影效果。

- `viewfinder.png`：全屏取景器、三分网格、画面分析（规则）推荐框与中文建议卡；底部渐变浮层上为焦段分段条、缩略图、居中快门与"调整"入口；顶部为构图/实时/AF 胶囊。
- `camera-picker.png`：控制面板"影调"分区的相机摆件选择与取景方向（自动/横持/竖持）弹窗。
- `edge-models.png`：控制面板"拍摄"分区底部的构图辅助管理——实时开关、三个可选端侧模型（SmolVLM 256M/500M、d1 决策 600M）与已安装 417.7MB 状态。

蓝色推荐框来自当前图像统计（画面分析建议），黄色框只在端侧模型选择通过领先差距与候选换序一致性门闸后出现。中文提示来自候选的规则理由，不伪装成模型生成。模型未选择、超时或未安装时保留画面分析建议。

截图用 ADB screencap 取得，原始 1080×2340 按比例缩至 720×1560；不拼接取景或虚构控件。UI 截图为 README 展示材料，原始测试输入与照片仅保存在被 Git 忽略的本地目录。三档焦段按设备能力开放，该模拟器 HAL 不报告数字变焦故显示为不可用灰态，真机行为可能不同。

更新截图时同步检查 README 与本文件描述。默认 Preview APK 不带权重（约 21MB），模型在 App 内显式下载；不能仅看默认包体判断模型是否存在。
